# リンキングのルール一覧

[← 目次に戻る](../README.md)

エンジニア英語でよく出る音の変化を 7 つに絞っています。
フレーズ集の 🔗 行はこのルールで書かれています。

| # | ルール | 記号 | 例 | 聞こえ方 |
|---|---|---|---|---|
| 1 | 子音 + 母音はつながる | `‿` | `run‿it` / `fix‿it` / `look‿at` | ラニッ / フィクシッ / ルッカッ |
| 2 | 語末の t / d は次が子音だと消える | `(t)` `(d)` | `jus(t) fix` / `buil(d) passes` | ジャス フィックス / ビル パスィズ |
| 3 | 母音にはさまれた t は d / ラ行っぽくなる（フラップ T） | `[d]` | `ge[d]‿it` / `forma[d]er` | ゲリッ / フォーマラー |
| 4 | nt の t が消える | `[n]` | `wa[n]‿to` / `twen[n]y` | ワナ / トゥウェニー |
| 5 | t + you → チュ、d + you → ジュ | `‿` | `wha(t)‿you` / `could‿you` | ワッチュ / クッジュ |
| 6 | 同じ・似た子音が並ぶと 1 回だけ発音 | `‿` | `la(st) time` / `bi(g) game` | ラスタイム / ビゲイム |
| 7 | 機能語（and, for, them, to）は弱く短く | — | `an(d)` / `fer` / `'em` / `ta` | ン / ファ / エム / タ |

## エンジニア頻出のつながり

```text
run it / fix it / check it out / look at it / push it / merge it / log in / set up
```

| 英語 | 聞こえ方 |
|---|---|
| run it | ラニッ |
| fix it | フィクシッ |
| check it out | チェキラウ |
| look at it | ルッカリッ |
| push it | プッシッ |
| merge it | マージッ |
| log in | ロギン |
| set up | セラッ |
| clean up | クリーナッ |
| spin it up | スピニラッ |

## コツ

1. **まずは区切って読む** → 次にリンキングを意識してつなげる → 最後に自然な速さで。
2. **強く読むのは内容語**（名詞・動詞・形容詞）。`the` `and` `for` `to` は弱く速く。
3. 文末の t は止めるだけで、はっきり「ト」と言わない（`commi(t)` = カミッ）。
